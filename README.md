## zuzuflow
신개념 투자 정보 커뮤니티 주식 가상화폐 시세를 예측하고 보상을 받으세요

## 개발 의도
이 커뮤니티를 만든 이유는 제가 증권방송을 보면서 자칭 전문가 또는 무슨 투자 대표라는 사람들이 얼토당토 않은 투자 전망으로 개인투자자들을 현혹시키는 경우를 많이 보았습니다 그래서 유튜브 댓글이나 네이버 토론방에 누구를 거론하면 삭제당하거나 명예훼손으로 고소를 당하게 됩니다 그래서 특정인을 거론하지 않아도 투자종목에 대한 의견을 개진할 수 있는 혁신적인 투자 정보 제공 시스템을 고안하게 되었습니다.

## 새 글 등록
새 글을 등록하기 위해서는 글을 저장한 다음 발행을 해야 합니다. 발행을 위해서는 Z코인이 필요합니다. Z코인은 커뮤니티 활동을 통해 얻은 포인트를 전환하여 얻을 수 있습니다. 추후 가상화폐 거래소에 Z코인이 상장되면 거래소에서 구입할 수 있습니다.
